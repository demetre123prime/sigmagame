# Neon Drift Arena

A polished single-file browser arcade game built with vanilla HTML, CSS and JavaScript.

## Play
Open `index.html` in a browser, or enable GitHub Pages for the repository.

### Controls
- WASD / Arrow keys — move
- Mouse — aim
- Hold mouse button — fire
- Space — dash
- P — pause
- Upgrade ship — spend cores on permanent run upgrades

## Gameplay
Survive escalating waves, destroy drones, collect cores, dash out of danger, and upgrade your ship. No external libraries or assets are required.
